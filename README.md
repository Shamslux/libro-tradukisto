<a id="english"></a>
## 🇬🇧 English

**Libro Tradukisto** is an open-source desktop application for translating EPUB ebooks and reviewing their translations. Its goal is to preserve the book's structure, formatting, links, images, and navigation while making the text available in another language.

### Features
- Import EPUB books and choose a target language.
- Translate using supported online translation services, cloud AI providers, or local inference options, depending on configuration.
- Review translated text with a side-by-side workflow.
- Export the translated EPUB while retaining non-text resources and book structure as far as supported.
- Check for application updates from within the desktop app.

### Installation
Download the Windows installer from the [latest GitHub release](https://github.com/Shamslux/libro-tradukisto/releases/latest). For development, see [Development](#development).

> **Note:** Translation quality, provider availability, costs, and preservation of complex EPUB layouts depend on the chosen service and the source book. Review the output before sharing it.

## Development

The current desktop application uses **Tauri v2**, **Rust**, **React**, **TypeScript**, and **Vite**. The project evolved from an earlier Python-based translator initially associated with the Esperanto community.

```bash
npm install
npm run tauri dev
```

To build a desktop release, use the scripts and signing configuration appropriate to your environment. Signed update artifacts require the project's release signing key; never commit private signing keys or passwords.

## Releases and updates

Windows builds and release notes are available on the [Releases page](https://github.com/Shamslux/libro-tradukisto/releases). The desktop app supports an updater; availability of automatic checks depends on the installed version.
